# 명화 카멜레온 V2 초안

## 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000`.

## 관리자
관리자 코드 입력칸에 `gmltn`을 입력하면 교사용 방이 생성됩니다. 관리자는 참여하지 않으며, 6자리 학생용 방 코드를 학생들에게 알려준 뒤 게임을 시작합니다.

## 현재 구현
- 최대 20명 멀티
- 관리자/학생 역할 분리
- 시작 시 술래/숨는 사람 역할을 미리 결정
- 5000x3200 대형 2D 월드 + 플레이어 중심 카메라
- 키보드 + 화면 조이스틱 이동
- 숨는 사람: 그리기 모드 + 몸 전체를 단일 캔버스처럼 칠하기
- 스포이드 모드(현재 맵의 구역 색을 추출)
- 술래: 화면 이동 + 가까운 숨는 사람 잡기
- 낮은 빈도의 서버 상태 브로드캐스트로 저사양 기기 고려
- 원작 명화/맵 이미지를 포함하지 않은 오리지널 테스트 맵
