# 명화 카멜레온 V4

20명까지 가능한 2D 멀티 숨바꼭질 웹게임 프로토타입입니다.

## 이번 버전 핵심
- 관리자 코드 `gmltn`: 관리자만 방을 만들고 게임을 시작함
- 관리자는 플레이어가 아니며 전체 맵과 역할을 항상 볼 수 있음
- 게임 시작 시 술래/숨는 사람을 미리 랜덤 배정
- 술래: 캐릭터를 표시하지 않고 화면 중앙 기준으로 넓은 맵을 이동하며 탐지
- 숨는 사람: 흰색 사람 실루엣 한 덩어리를 3가지 자세로 움직이고 색칠
- 그리기/스포이드/브러시 크기 지원
- 사람 외곽에 1px 검은 테두리
- 터치/마우스 이동 패드 + 키보드 이동
- 숨기 시간/찾기 시간/탐지 쿨다운/막판 쿨다운/탐지 범위/드러남 시간 설정
- 모나리자 맵 선택 가능

## 실행
1. Node.js 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. `http://localhost:3000`

## 관리자
관리자 코드 입력: `gmltn`

## 참고
모나리자 이미지는 사용자가 대화에서 제공한 이미지 파일을 게임의 맵 자원으로 사용합니다.
