# 명화 카멜레온 V3

20명까지 가능한 2D 멀티 숨바꼭질 프로토타입입니다.

## 실행
1. Node.js 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000`

## 관리자
- 관리자 코드: `gmltn`
- 관리자는 게임에 참여하지 않으며 방 생성/시작/설정만 담당합니다.
- 게임 시작 후 전체 맵에서 모든 참가자와 역할을 확인할 수 있습니다.

## 학생
- 방 코드 입력 후 입장합니다.
- 숨는 사람: 이동 패드, 마우스/터치 그림판, 스포이드, 3가지 자세
- 찾는 사람: 캐릭터 없이 맵 시점을 이동하며 화면을 눌러 탐지 펄스를 사용합니다.

## V3 설정
- 숨는 시간
- 찾는 시간
- 기본 탐지 간격
- 마지막 구간 탐지 간격
- 마지막 구간 길이
- 탐지 범위
- 드러남 시간

탐지 효과는 원작의 시각적 아이디어를 그대로 복제하지 않고, 무지개색에 가까운 **탐지 펄스**로 오리지널 UI를 구성했습니다.

명화 선택 기능은 데이터 구조를 분리해 다음 버전에서 맵을 추가하기 쉽게 설계할 수 있습니다.
